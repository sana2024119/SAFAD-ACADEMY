# SAFAD-ACADEMY# 

### Learn. Innovate. Lead.

SAFAD ACADEMY is a modern technology academy website designed to introduce visitors to different technology courses and provide information about the academy.

## About the Project

This project is a responsive multi-page website built as a web development project. It features a calm and elegant design inspired by the city of Safad.

## Website Pages

- **Home:** Introduction to the academy and featured courses.
- **Courses:** Displays the available technology courses.
- **Course Details:** Provides information about the Web Development course.
- **Contact & Registration:** Allows visitors to fill out a registration form.

## Courses

- Web Development
- Python Programming
- Artificial Intelligence
- Cybersecurity
- UI/UX Design
- Data Analytics

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Main Features

- Responsive design for different screen sizes.
- Navigation bar connecting all pages.
- Bootstrap cards, buttons, and forms.
- Consistent colors and elegant styling.
- Interactive registration form with a confirmation message.
